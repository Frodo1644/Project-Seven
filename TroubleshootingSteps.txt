# VST3 Loading Troubleshooting Guide

## Scenario
Cubase 15 cannot detect or load the Project Seven VST3 plugin.

## Step 1: Extract the Distribution ZIP
1. Download/extract `ProjectSeven-1.2.0-win64.zip`
2. Extract to a folder with no spaces or special characters:
   - Recommended: `C:\Program Files\Project Seven VST3\`
   - Or: `C:\Users\jaisw\Desktop\ProjectSevenVST3\` (for testing)

## Step 2: Verified File Structure
The extracted folder should contain:
```
Project Seven.vst3/
├── Contents/
│   ├── Resources/
│   │   └── moduleinfo.json
│   └── x86_64-win/
│       └── Project Seven.vst3 (this is the actual DLL)
```

**Note:** The `.vst3` file inside `x86_64-win\` is the actual plugin DLL, even though it has the same extension. Do not extract this file alone - the VST3 bundle must remain intact.

## Step 3: Scan for VST3 Plugins in Cubase 15

### Method A: VST3 Scan Program Picker (Recommended)
1. Open Command Prompt as Administrator
2. Navigate to Steinberg Cubase 15 installation folder:
   ```
   cd "C:\Program Files\Steinberg\Cubase 15"
   ```
3. Run the VST3 scanner:
   ```
   Vst3ScanProgramPicker.exe "C:\Program Files\Project Seven VST3"
   ```
4. The scanner will report if the VST3 can be loaded

### Method B: Cubase VST Plugin Manager
1. Open Cubase 15
2. Go to **Studio > Manage VST Plug-ins...**
3. Click the **Scan VST Plug-ins...** button (bottom of window)
4. Navigate to the folder where you extracted the VST3
5. Click **Select Folder** and wait for scan to complete
6. Check the list for "Project Seven"

### Method C: Start Cubase and Let It Auto-Scan
1. Open Cubase 15 (first time after installing new plugin)
2. Cubase should automatically scan known VST3 folders
3. Common folders it scans:
   - `C:\Program Files\Common Files\VST3\`
   - `C:\Program Files\Steinberg\VSTPlugins\`
   - Additional folders configured in Cubase preferences

## Step 4: Check if Plugin Appears

### In Cubase VST Plugin Manager
- Look for "Project Seven" in the list
- Manufacturer should show: **Project Seven Audio**
- Type should show: **Instrument**
- Format should show: **VST3**

### If Plugin Does Not Appear
1. Check the **Error** column for any loading errors
2. Try clicking **Rescan** button
3. Check Cubase preferences:
   - **Edit > Preferences > VST > Plug-in Manager**
   - Verify VST3 scan folders include where you extracted the plugin

## Step 5: Test the Plugin

### If Plugin Appears in Manager
1. Create a new empty Cubase project
2. Add an **Instrument Track** (not Audio Track)
3. In the track's instrument slot, select **Project Seven**
4. The editor window should open (dark industrial palette)
5. Play MIDI notes - you should hear sound
6. Check the mixer for output level

### If Plugin Loads but No Sound
1. Check track is not muted
2. Check track volume is up
3. Check MIDI input is connected
4. Verify the plugin is receiving MIDI (check MIDI monitor)
5. Try different MIDI notes (the instrument covers a wide range)

## Step 6: Check Windows Event Viewer for Errors

If Cubase reports an error or the plugin fails to load:

1. Open **Event Viewer** (Windows key + R, type `eventvwr.msc`)
2. Navigate to **Windows Logs > Application**
3. Look for errors related to:
   - Cubase
   - Project Seven
   - VST3
   - Missing DLLs
4. Note any error codes or messages

## Step 7: Check Dependencies

The VST3 requires:
- Windows 10 or later (built for Windows 10.0.26100.0 SDK)
- No Visual C++ Redistributable required (static runtime)
- No additional DLLs required

To verify:
1. Right-click the VST3 DLL (`Project Seven.vst3` in `x86_64-win\`)
2. Select **Properties > Details**
3. Check **Product version** and other metadata
4. Try opening with **Dependencies** tool (modern Dependency Walker) to verify all DLLs resolve

## Step 8: Try Alternative Installation Method

If scanning doesn't work:

1. Copy the entire `Project Seven.vst3` folder to:
   ```
   C:\Program Files\Common Files\VST3\Project Seven.vst3\
   ```
2. Restart Cubase 15
3. Cubase should detect it in the standard VST3 folder

## Step 9: Verify DLL Integrity

If you suspect the DLL is corrupted:

1. Check file size: should be around 8-9 MB
2. Check file hash (if available from build logs)
3. Rebuild from source if necessary using the build instructions in BUILD.md

## Step 10: Common Issues and Solutions

### Issue: "Plugin not found in scan"
- **Solution**: Ensure you're scanning the folder containing the `.vst3` bundle directory, not the DLL file itself

### Issue: "Missing DLL error"
- **Solution**: Verify all files were extracted. The bundle contains multiple files, not just the DLL

### Issue: "Cubase crashes when loading plugin"
- **Solution**: Check Windows Event Viewer for crash details. Could be incompatible Cubase version or corrupted build

### Issue: "Plugin appears but editor doesn't open"
- **Solution**: Check if there are any errors in Cubase console. Try restarting Cubase

### Issue: "No sound from plugin"
- **Solution**: 
  - Verify MIDI is being sent to the track
  - Check plugin parameters (volume, articulation, etc.)
  - Try different presets
  - Check Cubase mixer routing

## Need More Help?

2. Check CHANGELOG.md for recent changes
3. Rebuild the plugin from source following BUILD.md
4. Test with the smoke test executable to verify the VST3 works
5. Contact support with:

   - Windows version

   - Screenshot of VST Plugin Manager (if plugin appears but doesn't work)
